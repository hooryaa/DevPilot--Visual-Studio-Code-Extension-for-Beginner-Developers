# Security

DevPilot is open source and accepts responsible disclosure of security issues.

## Reporting Vulnerabilities

If you discover a security vulnerability, please open a GitHub issue or contact the maintainer directly via the repository issue tracker.

## Data Handling

DevPilot stores API keys and authentication tokens locally in VS Code secret storage. It does not share those secrets with third parties except through the chosen AI provider during normal AI requests.

## Scope

Security issues may include vulnerabilities in authentication, data handling, sandboxing, or third-party integrations such as OpenAI, Gemini, or FreeGPT endpoints.
