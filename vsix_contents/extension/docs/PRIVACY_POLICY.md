# Privacy Policy

DevPilot collects only the minimum information needed to provide its features.

## What DevPilot uses

- GitHub and Google authentication tokens are stored locally in VS Code secret storage for sign-in and session continuity.
- OpenAI or Gemini API keys are stored locally in VS Code secret storage when you choose to enable those providers.
- Optional usage data may be stored locally for dashboard and learning progress features.

## What is sent to third parties

When you use AI features, DevPilot sends your request text and relevant context to the selected provider (OpenAI, Gemini, or a FreeGPT-compatible endpoint) so that the AI service can generate a response.

## What is not collected

DevPilot does not upload your full workspace by default, and it does not sell or share personal data with advertisers.

## Local storage

Most authentication, API key, and preference data remain local to your machine and VS Code storage.

## Your choices

You can remove stored API keys or sign out at any time from the DevPilot commands in the Command Palette.
